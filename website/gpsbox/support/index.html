Support

This is the same page Settings → Support opens in the app. There is no in-app chat. Take your time. If a step is unclear, write in — we are glad to help.

Write in

Use the contact form and pick topic GPS BOX. Please include:

  • GPS BOX name (Account / setup page)
  • Whether the Ethernet cable is plugged into the house router
  • Whether Find GPS BOX found an address
  • The app version on the splash screen

If something is wrong

No lights on the GPS BOX

Power supply and outlet. Try another outlet. The official supply matters; a weak charger often fails.

Find GPS BOX finds nothing

Stay on house Wi‑Fi, not guest Wi‑Fi, not cellular. Seat the Ethernet cable. Wait 2 full minutes after power, then Find again. On a computer on the same Wi‑Fi, try http://gpsbox.local:8080/setup.

Setup page asks for a password you forgot

That is the setup-page password, not the phone lock. If you never changed it, first time is admin / password. If you changed it and lost it, you will need a new image on the card (that is a fresh start).

Scan does nothing

House Wi‑Fi. Camera permission. First phone QR for the first phone, Family QR for everyone else. Do not scan an old screenshot from last week if you pressed Reset.

Share is on but others see you red

Battery unrestricted. Location all the time. Wait a couple of minutes. If this phone is at home and they are away, they still need an active plan or trial to see live updates.

Setup page used to open, now it does not

The house number probably changed. Find GPS BOX again. Then reserve that address in the router so it stops moving.

I plugged in Wi‑Fi and a cable

The box uses the cable. Unplug the cable only if you intend to run on Wi‑Fi, then Save network on the Network page.
